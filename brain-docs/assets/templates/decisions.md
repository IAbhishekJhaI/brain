# Decisions Log

> **Maintenance:** append a dated entry here for every meaningful decision,
> newest-first, in the D/W/A/T format below — do this as you work, every
> session, not only when asked.

A running record of *meaningful* engineering decisions — the reasoning, the
alternatives rejected, and the tradeoffs accepted. Newest work at the top.

Legend: **D** = decision, **W** = why, **A** = alternative rejected,
**T** = tradeoff accepted. (An optional **Verified:** line records how the
change was proven to work.)
